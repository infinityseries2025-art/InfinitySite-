# Infinity Series — спортивное медиа

Отдельная рабочая копия публичных файлов сайта https://infinity-series-1f4c2.web.app/.
Исходная папка `InfinitySite--main` не изменена. Это не резервная копия базы,
правил доступа, секретов или настроек Firebase Hosting.

## Изменения

- Новая главная: редакционный первый экран, фирменный знак, статистика,
  матчи, новости и блок сообщества.
- Общая тема `assets/css/editorial.css` на всех десяти страницах.
- Сохранены фирменный розовый акцент, Firebase-проект и существующая логика.
- Собственный SVG-фон: координатная сетка, диагональные полосы и текстура.
- Контрастная шапка, многослойные панели, анимированная эмблема с орбитами.
- Появление карточек при прокрутке, лёгкий наклон центральной панели за
  курсором, анимация меню, кнопок и фоновых линий, индикатор прокрутки.
- Эффекты не блокируют показ контента без JavaScript; reduced-motion
  отключает CSS- и JS-анимации, в том числе при изменении настройки на лету.
- Фоновое движение приостанавливается в скрытой вкладке, движение эмблемы —
  также за пределами экрана. Постоянного JavaScript-цикла анимации нет.
- Адаптивная навигация, Escape для закрытия меню и видимый клавиатурный фокус.

## Локальный просмотр

Из этой папки: `node scripts/preview.mjs`, затем открыть http://localhost:4173.
Обычный `file://` не подходит: данные загружаются через fetch.

**Важно:** копия подключена к действующему Firebase-проекту. Регистрация,
отправка форм и изменения в админке могут записывать данные в настоящую базу.
Визуальный просмотр не требует отправлять формы. Для полноценного тестирования
используйте отдельный Firebase-проект или эмуляторы и тестовые аккаунты.

## Публикация

Автоматической публикации не выполнялось. При согласовании дизайна сначала
сверить эту конфигурацию Hosting с реальной конфигурацией проекта: она создана
для этой копии и не является выгрузкой настроек опубликованного сайта.
Выполнять деплой только после проверки функций и явного подтверждения.
