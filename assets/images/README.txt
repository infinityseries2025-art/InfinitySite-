Сюда клади свои картинки. Названия файлов менять не нужно —
сайт сам подхватит их, если файл существует, и покажет заглушку, если файла нет.

logo.png        — логотип турнира (квадратный, лучше на прозрачном фоне).
                  Показывается в шапке сайта и по центру главной страницы,
                  клик по нему ведёт на главную.

background.jpg  — фон всего сайта (необязательно). По умолчанию фон уже "зашит"
                  прямо в style.css, поэтому сайт красиво выглядит сразу,
                  даже если этот файл потеряется при загрузке на хостинг.
                  Если хочешь заменить фон на свой — положи сюда картинку
                  (желательно горизонтальную, не менее 1600px по ширине),
                  и сайт подставит её вместо встроенной. Если файла нет
                  или он не грузится (например 404 на GitHub Pages) —
                  ничего не сломается, останется встроенный фон.

favicon.png     — маленькая иконка вкладки браузера (уже есть заглушка).

Для новостей и команды картинки указываются не файлом, а ссылкой —
прямо в data/news.json (поле "image") и data/team.json (поле "photo").
Можно вставить туда ссылку на картинку, загруженную в этот же репозиторий,
например: "assets/images/news/anons.jpg".
